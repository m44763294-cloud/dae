# Запуск бота

Заполните файл `.env`: токен бота от BotFather, HTTPS-адрес мини-приложения и числовой ID группы для логов. Не публикуйте `.env` и никому не пересылайте токен.

Откройте PowerShell в этой папке и выполните:

```powershell
py -m pip install -r requirements.txt
py bot.py
```

Бот должен быть добавлен в группу и иметь право отправлять в неё сообщения. Сайт пока не передаёт событие начала проверки в бота: для этого нужен отдельный сервер. Partner API-ключи в группу не отправляются.

## Сервер событий

Для получения событий нужен постоянно работающий сервер с публичным HTTPS-адресом (статический хостинг сайта не запускает Python). В `.env` добавьте `WEBAPP_ORIGIN=https://адрес-сайта` без пути и завершающего слэша. Запустите `py -3.13 server.py` отдельно от бота и настройте HTTPS-прокси на его порт 8080 или задайте переменную `PORT` на хостинге. В `index.html` укажите `window.LIQUIDITY_EVENT_URL = 'https://адрес-сервера/api/liquidity-request'` и заново опубликуйте сайт. Сервер проверяет подпись Telegram initData и отправляет в группу Telegram ID и username; ключи не передаются. Это уведомление не запускает расчёт ликвидности.
